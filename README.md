# 📊 Bank Customer Churn Analysis - Power BI Dashboard  


## 📌 Project Overview  
This **Power BI dashboard** provides an insightful **churn analysis** of bank customers. It helps identify key factors contributing to customer churn by analyzing demographics, account balance, credit score, and product usage.  

### 🎯 Objectives  
✅ Understand customer churn trends and behaviors.  
✅ Identify key demographics affecting churn rates.  
✅ Analyze customer segmentation based on various attributes.  
✅ Provide actionable insights for improving customer retention.  

---

## 🏆 Key Insights from the Dashboard  
🔹 **Churn by Gender & Activity Status**: Breakdown of active vs. inactive customers.  
🔹 **Churn by Credit Card Ownership**: Identifies if credit card status impacts churn.  
🔹 **Country-wise Analysis**: Churn trends across different regions.  
🔹 **Age & Credit Score Impact**: How age groups and credit scores affect churn.  
🔹 **Account Balance Distribution**: Correlation between balance and churn probability.
